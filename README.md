# Jutopia

This is a package for topology optimization of two- and three-dimensional structures with structured and unstructured meshes. 

Topology optimization codes developed for educational purposes have been also rewritten in this Julia package to enhance performance and efficiency.

The package uses the power of [Comodo.jl](https://github.com/COMODO-research/Comodo.jl) for mesh generation and the power of  [Ferrite.jl](https://ferrite-fem.github.io/Ferrite.jl/stable/) for the finite element method.
